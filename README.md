# Точка действия — тест с закрытой базой участников

## Что внутри
- `index.html` — сайт теста с формой контактов перед вопросами.
- `app.py` — FastAPI-сервер и SQLite-база.
- `/admin` — закрытая страница владельца с контактами и результатами.
- `/admin/export.csv` — экспорт списка участников в CSV, также под паролем.
- `submissions.sqlite3` создаётся автоматически при запуске и не раздаётся посетителям.

## Запуск на Windows
1. Установите Python 3.11 или новее.
2. Распакуйте папку проекта.
3. Откройте PowerShell в этой папке.
4. Выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:ADMIN_USER = "owner"
$env:ADMIN_PASSWORD = "ЗАМЕНИТЕ_НА_ДЛИННЫЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ"
uvicorn app:app --host 127.0.0.1 --port 8000
```

5. Откройте тест: http://127.0.0.1:8000
6. Закрытая таблица владельца: http://127.0.0.1:8000/admin
   Введите логин `owner` и пароль, который задали в `ADMIN_PASSWORD`.
7. CSV-выгрузка находится по адресу http://127.0.0.1:8000/admin/export.csv

## Важно для публикации в интернете
- Не открывайте сайт как локальный HTML-файл двойным щелчком. Для сохранения данных сайт должен работать через FastAPI-сервер.
- На хостинге задайте переменные окружения `ADMIN_USER` и `ADMIN_PASSWORD` через панель управления хостингом. Не вписывайте пароль в `index.html`.
- Используйте HTTPS. Не размещайте административную страницу в интернете без HTTPS.
- Убедитесь, что выбранный хостинг сохраняет SQLite-файл между перезапусками. Если файловая система временная, подключите постоянный диск или внешнюю базу данных.
- До публикации добавьте политику обработки персональных данных и уточните юридические требования для своей юрисдикции. Форма требует согласия пользователя на сохранение контактных данных и ответов.
- База хранится в файле `submissions.sqlite3` рядом с `app.py`. Этот файл содержит персональные данные: ограничьте доступ к нему и делайте защищённые резервные копии.
